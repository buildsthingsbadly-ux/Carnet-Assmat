Carnet Assmat — mise en ligne et installation

Version 3.6.3 · environ 15 minutes · à faire une seule fois. Imprimez ce guide (Ctrl + P) pour l'avoir à côté de vous.

Les fichiers prêts à l'emploi sont dans Téléchargements\Assmat\a-publier : 6 fichiers et 2 dossiers (js avec 9 fichiers, icons avec 3 images). Ne modifiez rien dedans.

Étape 1 — Créer un compte GitHub (ordinateur)

  1. Allez sur github.com, cliquez Sign up.
  2. E-mail, mot de passe, et un nom d'utilisateur : il fera partie de l'adresse de l'appli (ex. marie-assmat).
  3. Validez le code reçu par e-mail.

Étape 2 — Créer l'espace de l'appli

  1. En haut à droite : + ▸ New repository.
  2. Repository name : carnet-assmat.
  3. Cochez Public (obligatoire pour la version gratuite). Seul le programme est visible : vos données ne quittent jamais le téléphone.
  4. Ne cochez rien d'autre ▸ Create repository.

Étape 3 — Envoyer les fichiers

  1. Cliquez le lien uploading an existing file.
  2. Ouvrez l'Explorateur Windows dans Téléchargements\Assmat\a-publier.
  3. Sélectionnez tout le contenu (Ctrl + A), pas le dossier lui-même, et glissez-le dans la page GitHub.
  4. Attendez que la liste affiche aussi js/… et icons/…, puis cliquez Commit changes.

✔ Vérification : la page de votre espace montre directement index.html, sw.js, js, icons… (et non un dossier « a-publier »).

Étape 4 — Activer la page web

  1. Settings (onglet en haut) ▸ Pages (menu de gauche).
  2. Branch : main, dossier : / (root) ▸ Save.
  3. Patientez 1 à 2 minutes, rafraîchissez : l'adresse s'affiche, du type https://VOTRE-NOM.github.io/carnet-assmat/.
  4. Envoyez-vous cette adresse par SMS ou e-mail.

Étape 5 — Installer sur le téléphone Android

  1. Ouvrez l'adresse dans Chrome (depuis un SMS ou un e-mail : « Ouvrir dans Chrome »). Internet est nécessaire cette première fois.
  2. Installez : bandeau « Installer l'application », ou menu ⋮ ▸ Installer l'application (ou « Ajouter à l'écran d'accueil ») ▸ Installer.
    Avec Samsung Internet : menu ☰ ▸ Ajouter la page à ▸ Écran d'accueil.
  3. Ouvrez désormais le carnet par l'icône Carnet Assmat de l'écran d'accueil.
  4. Vérifiez : passez en mode avion et ouvrez l'appli : elle fonctionne.

Étape 6 — Tablette (Android) et iPhone / iPad

  • Tablette Android : exactement l'étape 5, avec la même adresse.
  • iPhone / iPad : ouvrez l'adresse dans Safari ▸ bouton Partager (carré avec une flèche) ▸ Sur l'écran d'accueil. Installez-la vraiment : sur iPhone, un site non installé peut perdre ses données après quelques semaines sans visite.
  • ⚠️ Chaque appareil a ses propres données. Choisissez un appareil principal pour la saisie de tous les jours. Pour passer de l'un à l'autre, voir « Vos données et la copie de sécurité » plus bas.

Étape 7 — Premiers pas dans l'appli

  • Facultatif : Outils ▸ Essayer avec un exemple pour tout découvrir sans risque (vos vraies données sont mises de côté et reviennent en quittant la démo).
  • Outils ▸ Réglages ▸ Mon profil : nom, n° d'agrément, date et durée de l'agrément (5 ou 10 ans), zone de vacances scolaires.
  • Enfants ▸ Ajouter un enfant, pour chaque enfant. Un contrat déjà commencé ? Ouvrez « Contrat déjà commencé : reprendre les compteurs ».
  • Outils ▸ Mes données ▸ Faire une copie de sécurité, rangée dans Google Drive (voir la section suivante).
  • Facultatif : Aujourd'hui ▸ Ajouter les rappels à mon agenda (rappel du soir et du 25 du mois).
  • Vous aviez des données dans la version « fichier » sur l'ordinateur ? Ouvrez-la ▸ Outils ▸ Copie de sécurité, puis sur le téléphone ▸ Restaurer une copie.

Vos données et la copie de sécurité

Où sont vos données ? Uniquement dans la mémoire de l'appareil où l'appli est installée. Rien n'est envoyé sur internet : ni GitHub ni personne d'autre n'y a accès.

Enregistré tout seulDemande un appui
Chaque case remplie, dès la saisie.
Tout, quand vous quittez l'appli (appel, écran éteint, fermeture).
Une fiche enfant ou une journée commencée : elle est reprise telle quelle au retour.		 « ✔ Enregistrer » : valide la journée de l'enfant.
« Valider le mois » : range le mois dans l'historique de l'enfant.
« Faire une copie de sécurité » : jamais automatique.
⚠️ Sans copie, tout est perdu si vous désinstallez l'appli, effacez les données de Chrome, changez de téléphone, ou si le téléphone est perdu, cassé ou réinitialisé.

Faire une copie (1 minute) :

  1. Outils ▸ rubrique 💾 Mes données ▸ ⬆️ Faire une copie de sécurité.
  2. Le téléphone propose de partager le fichier : choisissez Drive (le plus sûr) ou envoyez-le-vous par Gmail. Sur ordinateur, le fichier va dans Téléchargements.
  3. Le fichier s'appelle copie-carnet-assmat-AAAA-MM-JJ.json. Il contient tout : enfants, contrats, suivi, mois validés, réglages et photos jointes. Gardez au moins la dernière copie de chaque mois.

✔ Sous les boutons, l'appli affiche la date de la dernière copie.

Quand la faire ?

  • Chaque mois, juste après « Valider le mois » : l'appli vous le propose (fenêtre « Faire une copie de sécurité ? » ▸ Oui, faire la copie ou Plus tard). La question n'est pas reposée si une copie a déjà été faite ce jour-là.
  • Avant de changer de téléphone, de le faire réparer ou de le réinitialiser.
  • En fin d'année : l'appli le rappelle dans Aujourd'hui. Elle vous signale aussi quand la dernière copie a plus de 2 mois.

Retrouver ses données (nouveau téléphone, tablette, après une réinstallation) :

  1. Installez l'appli sur l'appareil (étape 5 ou 6).
  2. Récupérez le fichier de copie sur l'appareil (Drive ou pièce jointe du mail ▸ Télécharger).
  3. Outils ▸ Mes données ▸ ⬇️ Restaurer une copie ▸ choisissez le fichier ▸ Oui, restaurer.
Restaurer remplace toutes les données de l'appareil par celles du fichier. Utilisez toujours la copie la plus récente, et ne restaurez pas une ancienne copie sur l'appareil où vous saisissez tous les jours.

Plus tard : publier une nouvelle version

  1. Sur github.com ▸ carnet-assmat ▸ Add file ▸ Upload files.
  2. Glissez de nouveau tout le contenu de a-publier (les anciens fichiers sont remplacés) ▸ Commit changes.
  3. Sur les téléphones, à la prochaine ouverture : bandeau « Mettre à jour » ▸ un appui. Les données ne sont pas touchées.
